# Chatinable Lite

**ZIP を解凍して実行するだけで、Java の学習環境がまるごと手に入る、
オールインワン学習デスクトップアプリです。**

インストールは不要で、JDK を別途用意する必要もありません。
教材・コードエディタ・実行環境・AI Mentor がひとつのアプリに統合されています。

Chatinable Lite は **BYOK 版**です。AI Mentor 機能はご自身の
[Gemini API キー](https://aistudio.google.com/apikey) で動作します
（Bring Your Own Key）。用意していただくキーは**この 1 つだけ**で、
チャットも音声読み上げも同じキーで動きます。UI・教材は**日本語のみ**です。

## ダウンロード

**配布ファイルは ZIP 1 本です。** Java の 3 コースがすべて収録されています。

| 配布ファイル | 収録コース | ダウンロード |
|---|---|---|
| `chatinable-lite-java-202609.01.05.zip` | Java 基礎編 / 上級編 / テスト 基礎＆実践 | [java-v202609.01.05](../../releases/tag/java-v202609.01.05) |

過去のバージョンを含むすべての配布物は [Releases](../../releases) にあります。

| | |
|---|---|
| 対応 OS | Windows 10 / 11（64bit） |
| ZIP サイズ | 約 227MB |
| 解凍後 | 約 450MB |
| 管理者権限 | 不要（インストールしないため） |

ZIP を解凍すると `chatinable-lite-java-202609.01.05/` というフォルダが 1 つでき、
その中の **`chatinable-lite-java.exe`** を実行すればアプリが起動します。
置き場所はどこでもかまいません（USB メモリに入れて持ち運ぶこともできます）。

実行ファイルは署名されていないため、初回起動時に SmartScreen の警告が出る場合があります。
「詳細情報」→「実行」で進めてください。

> **1.7.3 以前（インストーラ版）をお使いの方へ**
> 1.7.3 までは NSIS インストーラ（`chatinable-lite-java-setup-<版>.exe`）で配布していました。
> **ZIP 版は旧版を自動では削除しません。** Windows の「設定」→「アプリ」から
> **Chatinable Lite - Java** を先にアンインストールしてください。
> 設定（API キー・テーマ）と学習履歴は同じ場所を使い続けるので、そのまま引き継がれます。
>
> ZIP 版ではスタートメニュー・デスクトップのショートカットは作られません。
> 必要であれば `chatinable-lite-java.exe` のショートカットをご自身で作成してください。

## 初回設定

はじめてアプリを起動すると、**「👋 はじめての設定」** が開きます。
1 Gemini API キー → 2 テーマ → 3 声 → 4 Mentorタイプ の順に決めるだけです
（あとから ⚙ 設定でいつでも変更できます。もう一度見たいときは ⚙ 設定の
「はじめての設定をもう一度表示」から呼び戻せます）。

続いて **どのコースから始めるかを選ぶダイアログ**が開きます。
選んだコースの1問目がそのまま開き、画面の使い方ツアーが始まります。
次回からは前回の続きが復元されます。
コースはあとからヘッダーの「＋ 新規コース開始」「↻ 既存コース再開」でいつでも切り替えられます。

AI Mentor を使うには API キーの登録が必要です。「はじめての設定」の 1 番目で
登録できます（あとから ⚙ 設定パネルでも登録できます）。
キーは端末内の設定ファイルにのみ保存され（OS の資格情報ストア `safeStorage` で
暗号化されます）、送信先は Google の API だけです。

| キー | 用途 | 必須 | 取得先 |
|---|---|---|---|
| Gemini API キー | AI Mentor のチャット（ヒント・レビュー・自由質問）と回答の音声読み上げ | 必須 | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |

⚙ 設定パネルの Gemini API キー欄にある
**「API キーを取得する（Google AI Studio）」**リンクから、取得ページを直接開けます。

> **料金について**
> API の利用料金は、Google からお客様に直接請求されます。
> 本アプリの作者は課金に関与しません。

登録した API キーはすべてのコースで共有されるため、登録は 1 度だけで済みます。

## 収録コース

下表の 3 コースがすべて収録されています。

各コースは**講義レッスンと演習**で構成されています。まず講義で文法・仕組みを
図解つきで読み、続く演習で実際にコードを書いて確かめる流れです。

| コース | 種別 | 講義 | 演習 | 合計 |
|---|---|---|---|---|
| Java 基礎編 | Java | 58 | 136 | 194 |
| Java 上級編 | Java | 39 | 70 | 109 |
| Java テスト 基礎＆実践 | JUnit 5 / Gradle | 39 | 140 | 179 |

学習履歴はコースごとに分かれて記録されるため、3 コースを並行して進めても混ざりません。

## 同梱されるもの

個別インストールは一切不要です。すべてアプリに同梱されています。

| ランタイム | 内容 | 用途 |
|---|---|---|
| Java | Temurin JDK 25 を jlink で最小化（`javac` 同梱） | 全コース |
| Gradle Wrapper | `gradle-wrapper.jar` | Java テスト編のビルド・テスト実行 |
| Java 言語サーバー | Eclipse JDT Language Server | コード補完・エラー表示・定義ジャンプ |

Java テスト編では、初回のテスト実行時に Gradle Wrapper が Gradle 本体を自動取得します
（このときだけネットワーク接続が必要です）。

## 主な機能

- **設問 × エディタ × 実行結果 × AI Mentor** を1画面に統合
- **コード補完・エラー表示**（Java 言語サーバー）。書きかけのコードにその場で赤線が出て、
  クラス名やメソッド名は入力しながら補完できます。定義ジャンプ・ホバー表示にも対応
  （追加インストールは不要です）
- **講義レッスン**。図解つきの解説を1ステップずつ読み進められ、解説に合わせて
  エディタの該当行がハイライトされます
- **AI Mentor**（💡ヒント / 🔍レビュー / 自由質問）。会話は設問ごとに保持されます
- **音声読み上げ**。AI の回答を Gemini Live で音声解説（声・話し方を選択可）
- **ワークスペース**。書いたコードと学習履歴は `~/chatinable-lite/` に保存されます
- **ライト / ダークテーマ**、フォント・フォントサイズ変更
- **簡易ターミナル**
- **最新版のお知らせ**。起動時に一度だけこのリポジトリの最新リリースを確認し、新しい版が
  あればダウンロードページへ案内します（⚙ 設定の「最新版を確認」で手動確認も可能。
  自動更新はしません）

書いたコードと学習履歴はワークスペース（`~/chatinable-lite/`）にコースごとに分かれて保存されます。

## アンインストール

**解凍したフォルダごと削除**してください。インストールしていないため、
Windows の「設定」→「アプリ」には表示されません。

ワークスペース（`~/chatinable-lite/`）と設定は残ります。
完全に削除する場合は、以下も手動で削除してください。

```
%USERPROFILE%\chatinable-lite\
%APPDATA%\Chatinable Lite\
```
